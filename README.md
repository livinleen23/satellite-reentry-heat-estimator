#SATELLITE RE-ENTRY HEAT ESTIMATOR

#Project Overview
The satellite re-entry heat estimator is a python based programme that estimates the heat experienced by the satellite during the atmospheric re-entry 

When a satellite enters Earth's atmosphere at a very high speed. It experiences strong aerodynamic heating due to its interaction with atmosphere. This project uses basic aerospace concepts and python programming to provide a simplified estimate of heating during re-entry.

#Objectives
The main objectives of this project are:
>To understand the heating experienced during atmospheric re-entry
>To apply basic aerospace engineering concepts using python
>To calculate an estimated heating value using user inputs
>To understand the relationship between velocity, altitude, and atmospheric heating
>To develop a simple and user-friendly Python programme

#Features

Parameter    | Description                        | Unit

#Basic Principle 
During atmospheric re-entry, the satellite travels through the atmosphere at a very high velocity.

A simplified relationship for aerodynamic heating can be represented as:

Heating is directly proportional to rho*V^3

where:
'rho' = atmospheric Density
'V' = Velocity

This shows that velocity has a strong effect on aerodynamic heating.

Actual spacecraft re-entry heating is more complex and depends on several factors such as atmospheric density, velocity, spacecraft shape, trajectory, and surface properties.

Therefore, this project is intended as an educational estimator
